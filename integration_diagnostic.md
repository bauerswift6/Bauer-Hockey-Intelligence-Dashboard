## Choices I made that were not fully specified
- **Part 6 run method:** started the app with `DISABLE_CONTRACT_REFRESH=1` (its own
  guard) rather than STOPping, because without it the stale-snapshot refresher
  would rewrite `data/contracts_current.json`. With it, the app writes no project
  file (verified by before/after listing). `__pycache__` `.pyc` regeneration is the
  only filesystem change and is excluded from the listing/md5 set.
- **Snapshot endpoints:** used `/api/players-full` + `/api/leaders` as the "main
  skater leaderboard", `/api/goalies-full` + `/api/goalie-analytics` as the goalie
  leaderboards, and `/api/player/<id>` for all 8 named players (incl. goalies).
- **Class of `ixg`/on-ice/team xG:** classified **REBUILT** (they display xG) even
  though a v2 aggregate file does not exist yet — flagged as a blocking dependency
  in Part 7-D rather than silently leaving them old.
